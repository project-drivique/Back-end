# HU-BE-24 — Promociones y cupones

Usa `catalog.promotions` y `catalog.user_coupon_usages` de HU-BD-25. La validación
requiere usuario autenticado, verifica vigencia, días mínimos, cupo global y uso previo;
calcula el descuento con la tarifa del vehículo. Las promociones para banners son públicas.
